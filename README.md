# LIC Agent Portal - Demo

A front-end internship demo inspired by an insurance agent portal workflow.

## Modules
Dashboard, My Customers, My Policies, Premium Due, Renewals, New Proposal,
Leads, Commission & Earnings, Claims, Reports and Agent Profile.

## Technology
HTML5 + CSS3 + JavaScript + LocalStorage.

## Run
Open `login.html` in a browser. Use the demo Agent ID/password shown in the form.
Records are stored in browser LocalStorage.

## Important
This is NOT an official LIC portal and does not connect to LIC systems.
No official credentials, customer data, APIs or authentication are included.
Use it only as a UI/academic internship demonstration.
